# ملاذ / MLD

تم تحديث هوية الواجهة لتستخدم الأفتار الذي زوّده مالك السيرفر مباشرة، مع لوحة ألوان مستخرجة من الهوية البصرية: فحمي، أسود ناعم، فضي، أبيض لؤلؤي ووردي باهت.

## طريقة الوصول

- تصفح الصفحة الرئيسية والأعضاء والتقييمات متاح بدون تسجيل.
- إنشاء أو الانضمام إلى الألعاب والقروبات يتطلب حساب الموقع.
- لا يطلب الموقع تسجيل دخول Discord في الواجهة العامة.
- الربط الكامل مع Discord يحتاج تشغيل Discord Bot وبيانات التطبيق في Railway Variables؛ لا تضع التوكن داخل GitHub.

## متغيرات الربط المقترحة

```text
DISCORD_BOT_TOKEN=ضع_التوكن_في_Railway_فقط
DISCORD_CLIENT_ID=معرف_التطبيق
DISCORD_GUILD_ID=معرف_السيرفر
DISCORD_OWNER_ID=معرف_حساب_المالك
DISCORD_INVITE_URL=رابط_الدعوة
BOT_SHARED_SECRET=قيمة_عشوائية_مشتركة
```

لا يمكن للموقع جلب أعضاء السيرفر أو إنشاء الرومات أو إرسال الرسائل الخاصة فعلياً من دون Bot يعمل بصلاحيات Discord المناسبة. النسخة الحالية تحفظ طلبات الألعاب والقروبات والسينما والتحميل عبر API لتقرأها خدمات البوت المستقلة.

> استخدم المحتوى الذي تملك حق عرضه أو تنزيله فقط، ولا تتجاوز حماية أو خصوصية أي منصة.
