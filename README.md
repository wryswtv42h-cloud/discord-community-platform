# زاجل – Community Hub

نسخة إطلاق أولية لمنصة مجتمع عربية 기반 على Discord، مصممة بشكل خاص للـ UI الداكن، القروبات، الألعاب، السينما، الكنترول، التقييمات، والإحصائيات.

## التشغيل محلياً

```bash
npm install
npm start
```

ثم افتح:

```text
http://localhost:3000
```

## بيانات المدير الافتراضية

في أول تشغيل يتم إنشاء حساب الإدارة تلقائياً:

```text
اسم المستخدم: admin
الرمز: change-me-now
```

يفضل تغييرها فوراً عبر متغيرات البيئة في Railway:

```bash
ADMIN_USERNAME=your_admin_name
ADMIN_PASSWORD=very_strong_password
JWT_SECRET=random_long_secret
```

## النشر على Railway

1. اختر New Project
2. اختر Deploy from GitHub Repo
3. اختر هذا المستودع
4. أضف المتغيرات التالية
5. تأكد من أن المسار `/app/data` له Volume

## ملاحظات مهمة

- هذه نسخة إطلاق أولية، وليست خدمة Discord bot حقيقية بشكل كامل.
- السينما والكنترول جاهزان كـ queues للتفاعل مع خدمات خارجية مستقلة.
- لا تضع tokens أو كلمات سر داخل الكود، استخدم Railway Variables فقط.
- لتحويل المشروع إلى إنتاج كامل، أضف PostgreSQL و Redis وبوات Discord منفصلة.

## نظرة سريعة على المزايا

- صفحة رئيسية مشابهة للموقع المرجعي
- تسجيل دخول وإنشاء حساب
- جلسات ألعاب عامة
- إنشاء قروبات وطلبات انضمام
- قسم سينما مع جلسات وسائط
- قسم كنترول لتحليل الروابط
- تقييمات المجتمع
- إحصائيات الزيارات واللوجات
- دعم Discord في الشريط الجانبي

## احتياطات

- لا تستخدم محتوى مملوك أو محمي دون صلاحية.
- جميع خدمات التحميل أو عرض المحتوى يجب أن تكون قانونية ومصرح بها.
- إذا رغبت في ربط بوتات Discord حقيقية، فأنشئ خدمة مستقلة منفصلة مع OAuth2 و Discord API.
